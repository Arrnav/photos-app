# Immich OpenAPI spec

`immich-openapi-specs.json` is Immich's OpenAPI description of its server API, copied unchanged from
the Immich repository (`open-api/immich-openapi-specs.json`, tag `v3.3.5`). It belongs to the Immich
project (https://github.com/immich-app/immich), which is licensed under AGPL-3.0.

This app uses it only as an interface description to generate an API client
(`Scripts/generate-api.sh`). No Immich code is included in this repository.
